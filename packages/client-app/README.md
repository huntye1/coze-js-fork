# Rsbuild project

## Setup

Install the dependencies:

```bash
pnpm install
```

## Get started

Start the dev server:

```bash
pnpm dev
```

Build the app for production:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```

## Tauri Development

Start Tauri development server:

```bash
pnpm tauri dev
```

Build Tauri application:

```bash
pnpm tauri build
```

Note: Make sure you have installed the system dependencies required by Tauri before using it. For more details, please refer to the [Tauri official documentation](https://tauri.app/v1/guides/getting-started/prerequisites).
